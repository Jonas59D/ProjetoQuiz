# Quiz de Tecnologia

Um quiz interativo sobre conceitos básicos de Tecnologia da Informação (TI), desenvolvido com HTML, CSS e JavaScript. O projeto permite que os usuários respondam a perguntas de múltipla escolha e visualizem seus resultados com um gráfico de pizza.

## Funcionalidades

- **Tela de Início**: Solicita o nome do usuário para iniciar o quiz.
- **Perguntas**: 15 perguntas de múltipla escolha sobre TI, HTML, CSS, JavaScript e conceitos gerais de computação.
- **Navegação**: Botão "Próxima" para avançar entre as perguntas.
- **Pontuação**: Conta acertos e erros em tempo real.
- **Resultado Final**: Exibe desempenho com mensagem personalizada, percentual de acertos e gráfico visual.
- **Reinício**: Permite refazer o quiz sem recarregar a página.
- **Responsivo**: Design adaptável para dispositivos móveis e desktop.
- **Animações**: Transições suaves e efeitos visuais para melhor experiência.

## Tecnologias Usadas

- **HTML5**: Estrutura da página e elementos do quiz.
- **CSS3**: Estilização, layout responsivo e animações.
- **JavaScript (ES6+)**: Lógica do quiz, manipulação do DOM e interatividade.
- **Chart.js**: Biblioteca para gerar o gráfico de resultados (pie chart).

## Como Executar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Firefox, Edge, etc.).
3. Digite seu nome na tela inicial e clique em "Iniciar Quiz".
4. Responda às perguntas clicando nas opções.
5. Veja o resultado final e, se desejar, refaça o quiz.

Não há necessidade de servidor local ou dependências adicionais, pois o projeto é puramente front-end.

## Estrutura do Projeto

- `index.html`: Arquivo principal HTML com a estrutura da página.
- `styles.css`: Arquivo de estilos CSS para aparência e responsividade.
- `scripts.js`: Arquivo JavaScript com a lógica do quiz, perguntas e funções.

## Exemplo de Uso

1. Abra `index.html` no navegador.
2. Digite "João" no campo de nome e clique em "Iniciar Quiz".
3. Responda às perguntas (ex.: "O que significa a sigla 'TI'?" -> "Tecnologia da Informação").
4. No final, veja acertos, erros e o gráfico de desempenho.
